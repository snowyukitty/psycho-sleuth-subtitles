A small, unofficial Windows x64 tool that combines translations already present in your installed copy of Psycho-Sleuth. No added voices, API keys or game-text upload. No game assets or full dialogue script are distributed.

| Menu choice | Top | Bottom |
| --- | --- | --- |
| 1 | Traditional Chinese | English |
| 2 | Traditional Chinese | Japanese |
| 3 | Japanese | English |

Extract the whole ZIP, close the game and pause Steam updates, then double-click **Install.cmd**. Keep the `_tool` folder alongside it. Run Install.cmd again to switch pairs; **Restore.cmd** restores the original files. In the game, select Traditional Chinese or Japanese as the text language; either setting displays the selected pair.

The first launch downloads about **12 MB** of official Python runtime and verifies its pinned SHA-256. No Python installation is required. The package contains readable runtime scripts, the supported-file profile, instructions and terms. This repository hosts the player documentation and releases.

## Preview status

Only supported, unmodified Windows Steam files are accepted. Unknown updates and other mods are refused. Story dialogue, scenario choices and cutscene subtitles are covered; menus, names and clue UI retain the game's selected language. A few dense pages use inline pairs. The original Traditional Chinese prologue subtitles are missing, so that section shows the available other language.

The installer has passed tests on isolated copies for all three pairs, switching, voice/control preservation, interrupted-installation recovery and exact restoration. Actual in-game visual qualification remains pending. The Simplified Chinese guide does not add Simplified Chinese subtitle pairs.
