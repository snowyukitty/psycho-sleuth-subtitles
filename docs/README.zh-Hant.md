# 異病偵探 Psycho-Sleuth 雙字幕 — 使用說明

[English](README.en.md) · [日本語](README.ja.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md)

這是非官方的 **Windows x64 預覽版**，使用遊戲本機已有的翻譯組合雙字幕。不新增配音，不需要 API key，不上傳遊戲文字，也不附帶遊戲素材或完整劇本。

## 安裝

1. 從 [Release 頁面](https://github.com/snowyukitty/psycho-sleuth-subtitles/releases/tag/v0.2.0-preview.1)下載 **Psycho-Sleuth-Subtitles-0.2.0-preview.1-Minimal.zip**。
2. 將整個 ZIP 解壓到可寫入的資料夾。保留 `_tool` 資料夾，與啟動檔放在一起。
3. 關閉遊戲，暫停 Steam 更新，雙擊 **Install.cmd**。
4. 工具通常會自動找到 Steam 遊戲；若要求輸入路徑，貼上遊戲資料夾即可。遊戲資料夾必須可寫入。
5. 先選**上方字幕**，再選**下方字幕**。兩個畫面的編號相同；下方選單會排除已選的語言。

| 編號 | 語言 |
| --- | --- |
| 1 | English — 英文 |
| 2 | 日本語 — 日文 |
| 3 | 繁體中文 |
| 4 | 简体中文 — 簡體中文 |

任選兩種不同語言，共 **6 種配對、12 種上下排列**，包含繁中／簡中。例如 **1 → 4** 是英文在上、簡中在下；**4 → 1** 則相反。選好下方語言後立即開始安裝。第一個畫面可按 **R** 還原、**0** 離開；第二個畫面按 **0** 返回。注意：新版編號4是簡體中文，還原請用 R 或 Restore.cmd。

6. 遊戲內的文字語言請選 **繁體中文或日文**。兩種設定都會顯示本工具選定的字幕組合。

首次執行需要網路，會下載約 **12 MB** 的官方 Python 執行環境，並在執行前核對 SHA-256。不需要自行安裝 Python，也不會改動系統的 Python。下載的執行環境會保留在 `_tool` 內，供下次使用。

## 切換與還原

關閉遊戲後，再執行 Install.cmd 即可切換組合。雙擊 **Restore.cmd** 可以精確還原原版檔案。備份位於 `Psycho Sleuth_Data/.psycho-sleuth-subtitles/original`，還原完成前請保留。若安裝中斷，重新執行 Install 或 Restore，恢復完成前不要啟動遊戲。

**從 0.1.0-preview.1 升級：** 將新版 ZIP 解壓到另一個資料夾，執行新版 Install.cmd。工具確認舊版安裝狀態後，會沿用已驗證的原版備份，不需要手動還原。請保留遊戲內的 `.psycho-sleuth-subtitles` 資料夾。若 Steam 或其他工具改過檔案，仍須通過相容性檢查。

Steam 更新遊戲後，**請勿用舊備份覆蓋新檔案**。工具會拒絕未知版本與其他模組。如果恢復被拒絕，先完成 Steam 的 **「驗證遊戲檔案完整性」**，再將 `.psycho-sleuth-subtitles` 資料夾移到遊戲之外保留，等待支援新版本的工具。

## 範圍與預覽限制

- 支援劇情對白、劇情選項、過場字幕；選單、名稱、線索介面維持遊戲選定的語言。
- 多數字幕上下排列；少數密集短句依選定順序使用同行對照，保留原有點擊節奏。原文完全相同時只顯示一次。
- 原版序章動畫缺繁中字幕；含繁中的配對在該處只顯示另一種選定語言，選簡中就顯示簡中。原始字幕時間不同的區間，也可能短暫只顯示一種語言。所選兩種譯文不齊全的對白列維持原樣；若遊玩時遇到這些列，會依遊戲目前的文字語言顯示（也可能為空白），不會顯示選定的雙字幕。
- 繁體與簡體中文分別使用遊戲原有的**獨立譯文**，不透過自動繁簡轉換。
- 接受已支援的未修改原版檔案，或可辨識的本工具安裝狀態。12 種排列已通過隔離資料測試；長句、選項、字型及過場字幕的實際遊戲畫面驗收仍未完成。英文及簡中遊戲介面設定的字型顯示尚未驗收，請先使用上述建議的遊戲文字設定。
