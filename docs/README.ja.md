# Psycho-Sleuth 二言語字幕 — 使い方

[English](README.en.md) · [日本語](README.ja.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md)

ゲームに収録済みの翻訳を組み合わせて表示する、非公式の **Windows x64 向けプレビュー版**です。音声の追加、API キー、ゲーム内テキストのアップロードは不要です。ゲーム素材や台本全文は同梱していません。

## インストール

1. [リリースページ](https://github.com/snowyukitty/psycho-sleuth-subtitles/releases/tag/v0.2.0-preview.1)から **Psycho-Sleuth-Subtitles-0.2.0-preview.1-Minimal.zip** をダウンロードします。
2. ZIP 全体を書き込み可能なフォルダーに展開します。`_tool` フォルダーは削除せず、起動用ファイルと一緒に置いてください。
3. ゲームを終了し、Steam の更新を一時停止してから **Install.cmd** をダブルクリックします。
4. 通常は Steam のゲームを自動検出します。入力を求められた場合は、ゲームフォルダーのパスを貼り付けてください。ゲームフォルダーへの書き込み権限が必要です。
5. **上段**の言語を選び、次に**下段**の言語を選びます。番号は両画面で共通です。下段の画面には、上段で選んだ言語以外の3言語が表示されます。

| 番号 | 言語 |
| --- | --- |
| 1 | English — 英語 |
| 2 | 日本語 |
| 3 | 繁體中文 — 繁体字中国語 |
| 4 | 简体中文 — 簡体字中国語 |

異なる2言語を自由に選べます。繁体字・簡体字の組み合わせも含め、**6組、上下の順序を含めて12通り**です。例：**1 → 4** は上段が英語、下段が簡体字中国語。**4 → 1** で逆になります。下段を選ぶとインストールが始まります。最初の画面では **R** で復元、**0** で終了。次の画面では **0** で戻ります。旧版と異なり、番号4は復元ではなく簡体字中国語です。

6. ゲーム内のテキスト言語を **繁体字中国語または日本語** に設定します。対訳が揃った会話では、どちらの設定でも本ツールで指定した組み合わせが表示されます。例外は下記「対象範囲・プレビュー版の制限」をご確認ください。

初回起動時のみ、公式 Python 実行環境を約 **12 MB** ダウンロードするため、インターネット接続が必要です。実行前に SHA-256 を確認します。Python の事前インストールは不要で、システムの Python 設定も変更しません。実行環境は `_tool` 内に保存され、次回以降も使用されます。

## 組み合わせの変更・元に戻す

ゲームを終了してから Install.cmd を再実行すると、組み合わせを変更できます。**Restore.cmd** をダブルクリックすると、元のファイルに正確に戻します。バックアップは `Psycho Sleuth_Data/.psycho-sleuth-subtitles/original` にあります。復元が終わるまでは保管してください。処理が中断された場合は Install または Restore を再実行し、復旧が完了するまでゲームを起動しないでください。

**0.1.0-preview.1 からの更新：** 新しい ZIP を別のフォルダーに展開し、その Install.cmd を実行します。既存の適用状態を確認できれば、検証済みの元ファイルのバックアップを再利用するため、手動で元に戻す必要はありません。ゲーム内の `.psycho-sleuth-subtitles` は保管してください。Steam や他のツールがファイルを変更した場合は、互換性確認の対象になります。

Steam でゲームが更新された後は、**古いバックアップを新しいゲームファイルに上書きしないでください**。未対応バージョンや他の MOD がある場合は処理を拒否します。復旧できない場合は、先に Steam の **「ゲームファイルの整合性を確認」** を完了してください。その後 `.psycho-sleuth-subtitles` をゲームフォルダーの外へ移して保管し、対応版の公開をお待ちください。

## 対象範囲・プレビュー版の制限

- シナリオの会話、選択肢、動画字幕が対象です。メニュー、名前、手がかりの UI はゲーム側で選んだ言語のままです。
- 通常は上下二段表示です。一部の短文が連続するページでは、元のクリックのタイミングを保つため、選択した順序で同じ行に併記します。原文が同一の場合は1回だけ表示します。
- 原版のプロローグ動画には繁体字字幕がありません。繁体字を含む組み合わせでは、もう一方の選択言語だけを表示します。簡体字を選んだ場合は簡体字になります。元の表示時間が異なる区間でも、一方の言語だけになることがあります。選んだ2言語が揃わない会話の行は変更しません。その行がゲーム中に使われる場合、選んだ字幕の組み合わせではなく、ゲーム側の現在の言語で表示されます（空欄の場合もあります）。
- 繁体字と簡体字には、ゲームに収録された**それぞれの翻訳**を使用します。文字の自動変換は行いません。
- 対応する未改変ファイル、または本ツールによる適用状態を確認できるファイルに対応します。12通りのデータ検証は完了していますが、長文、選択肢、フォント、動画字幕のゲーム画面上での検証は未完了です。英語・簡体字のゲーム内言語設定でのフォント表示も未検証のため、上記の推奨設定をご使用ください。
