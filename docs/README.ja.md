# Psycho-Sleuth 二言語字幕 — 使い方

[English](README.en.md) · [日本語](README.ja.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md)

ゲームに収録済みの翻訳を組み合わせて表示する、非公式の **Windows x64 向けプレビュー版**です。音声の追加、API キー、ゲーム内テキストのアップロードは不要です。ゲーム素材や台本全文は同梱していません。

## インストール

1. [リリースページ](https://github.com/snowyukitty/psycho-sleuth-subtitles/releases/tag/v0.1.0-preview.1)から **Psycho-Sleuth-Subtitles-0.1.0-preview.1-Minimal.zip** をダウンロードします。
2. ZIP 全体を書き込み可能なフォルダーに展開します。`_tool` フォルダーは削除せず、起動用ファイルと一緒に置いてください。
3. ゲームを終了し、Steam の更新を一時停止してから **Install.cmd** をダブルクリックします。
4. 通常は Steam のゲームを自動検出します。入力を求められた場合は、ゲームフォルダーのパスを貼り付けてください。ゲームフォルダーへの書き込み権限が必要です。
5. 番号を入力します。

| 番号 | 上段 | 下段 |
| --- | --- | --- |
| 1 | 繁体字中国語 | 英語 |
| 2 | 繁体字中国語 | 日本語 |
| 3 | 日本語 | 英語 |
| 4 | 元のファイルに戻す | |
| 0 | 終了 | |

6. ゲーム内のテキスト言語を **繁体字中国語または日本語** に設定します。どちらを選んでも、このツールで指定した字幕の組み合わせが表示されます。

初回起動時のみ、公式 Python 実行環境を約 **12 MB** ダウンロードするため、インターネット接続が必要です。実行前に SHA-256 を確認します。Python の事前インストールは不要で、システムの Python 設定も変更しません。実行環境は `_tool` 内に保存され、次回以降も使用されます。

## 組み合わせの変更・元に戻す

ゲームを終了してから Install.cmd を再実行すると、組み合わせを変更できます。**Restore.cmd** をダブルクリックすると、元のファイルに正確に戻します。バックアップは `Psycho Sleuth_Data/.psycho-sleuth-subtitles/original` にあります。復元が終わるまでは保管してください。処理が中断された場合は Install または Restore を再実行し、復旧が完了するまでゲームを起動しないでください。

Steam でゲームが更新された後は、**古いバックアップを新しいゲームファイルに上書きしないでください**。未対応バージョンや他の MOD がある場合は処理を拒否します。復旧できない場合は、先に Steam の **「ゲームファイルの整合性を確認」** を完了してください。その後 `.psycho-sleuth-subtitles` をゲームフォルダーの外へ移して保管し、対応版の公開をお待ちください。

## 対象範囲・プレビュー版の制限

- シナリオの会話、選択肢、動画字幕が対象です。メニュー、名前、手がかりの UI はゲーム側で選んだ言語のままです。
- 通常は上下二段表示です。一部の短文が連続するページでは、元のクリックのタイミングを保つため同じ行に併記します。
- 原版のプロローグ動画には繁体字字幕がありません。その箇所では、利用可能な英語または日本語のみを表示します。元の字幕の表示時間が異なる区間でも、一方の言語だけになることがあります。
- 中国語字幕は **繁体字** です。簡体字の使用説明書があっても、簡体字字幕の組み合わせが追加されるわけではありません。
- 対応する未改変のゲームファイル専用です。長文、選択肢、フォント、動画字幕のゲーム画面上での検証は、まだ完了していません。
