# Psycho-Sleuth 二言語字幕 — 使い方

[English](README.en.md) · [日本語](README.ja.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md)

ゲームに収録済みの公式翻訳を組み合わせて表示する、非公式の **Windows x64 向けプレビュー版**です。音声の追加、API キー、ゲーム内テキストのアップロードは不要です。ゲーム素材や台本全文は同梱していません。

## インストール

1. [`v0.2.0-preview.1` リリースページ](https://github.com/snowyukitty/psycho-sleuth-subtitles/releases/tag/v0.2.0-preview.1)から **Psycho-Sleuth-Subtitles-0.2.0-preview.1-Minimal.zip** をダウンロードします。
   *（任意チェック：PowerShell で `Get-FileHash .\Psycho-Sleuth-Subtitles-0.2.0-preview.1-Minimal.zip` を実行し、`SHA256SUMS.txt` と一致するか確認できます。）*
2. ZIP 全体を書き込み可能なフォルダーに展開します。`_tool` フォルダーは削除せず、`Install.cmd`・`Restore.cmd` と同じ場所に置いてください。
3. *Psycho-Sleuth* を完全に終了し、Steam の自動更新を一時停止してから **Install.cmd** をダブルクリックします。
4. 通常は Steam のゲームフォルダーを自動検出します。入力を求められた場合は、書き込み可能なゲームフォルダーのパスを貼り付けてください。
5. **上段**の言語を選び、次に**下段**の言語を選びます。番号は両画面で共通です。下段の画面には上段で選んだ言語以外の3言語が表示されます。

| 番号 | 言語 |
| --- | --- |
| 1 | English — 英語 |
| 2 | 日本語 |
| 3 | 繁體中文 — 繁体字中国語 |
| 4 | 简体中文 — 簡体字中国語 |

異なる2言語を自由に選べます。繁体字・簡体字の組み合わせも含め、**6組、上下の順序を含めて12通り**です。例：**1 → 4** は上段が英語、下段が簡体字中国語。**4 → 1** で逆になります。下段を選ぶとインストールが始まります。最初の画面では **R** で復元、**0** で終了。次の画面では **0** で戻ります。*（0.2.0-preview.1 では番号4は復元ではなく簡体字中国語です。）*

6. ゲーム内のテキスト言語を **繁体字中国語** または **日本語** に設定します。対訳が揃った会話では、どちらの設定でも本ツールで指定した組み合わせが表示されます。例外は下記「対象範囲・プレビュー版の制限」をご確認ください。

初回起動時のみ、公式の Python 3.14.10 埋め込み版実行環境（約 **12 MB**）を `python.org` からダウンロードするため、インターネット接続が必要です。実行前にピン留めされた SHA-256 を検証して `_tool\python-runtime.zip` に保存し、起動ごとにハッシュを再確認した上で `%TEMP%` 配下の一時フォルダーへ展開します（終了時に一時フォルダーは自動削除されます）。Python の事前インストールは不要で、システム側の Python 環境も変更しません。

### コマンドライン実行（任意）

**展開先のフォルダーで** PowerShell またはコマンドプロンプトを開き、`Install.cmd` / `Restore.cmd` に引数を渡すこともできます。

- `.\Install.cmd --pair en-ja` — 対話メニューをスキップして指定ペア（`上段-下段`）を適用
- `.\Install.cmd --top ja --bottom zh-Hant` — 上段・下段を明示指定（`en`, `ja`, `zh-Hant`, `zh-Hans`）
- `.\Install.cmd --list-pairs` — 対応する12通りを一覧表示
- `.\Restore.cmd` — 元のゲームファイルへ即座に復元

## 組み合わせの変更・アップデート・元に戻す

ゲームを終了してから **Install.cmd** を再実行すると、いつでも組み合わせ変更や上下入替ができます。**Restore.cmd** をダブルクリックすると、元のファイルにバイト単位で正確に戻します。検証済みバックアップは `Psycho Sleuth_Data/.psycho-sleuth-subtitles/original` に保存されるため、復元完了まで `.psycho-sleuth-subtitles` を残してください。処理が中断された場合は、Install または Restore を再実行して復旧を完了させてからゲームを起動してください。

**0.1.0-preview.1 からの更新：** 新しい ZIP を別のフォルダーに展開し、新しい `Install.cmd` を実行します。既存の適用状態を認識できれば、検証済みの元ファイルバックアップを自動で再利用するため、手動で戻す必要はありません。ゲーム内の `.psycho-sleuth-subtitles` は削除しないでください。Steam や他ツールによる変更があった場合は互換性チェックが働きます。

**Steam でゲームが更新された後：** **古いバックアップを新しいゲームファイルに上書きしないでください**。未対応バージョンや他 MOD は安全のため拒否されます。更新後に復旧できない場合は、先に Steam の **「ゲームファイルの整合性を確認」** を完了し、`.psycho-sleuth-subtitles` をゲームフォルダーの外へ退避してから対応版の公開をお待ちください。

## トラブルシューティング

- **「ゲームが起動中です」と表示される：** Steam またはタスクマネージャーからゲームを完全に終了してやり直してください。
- **初回起動の Python ダウンロードが進まない：** セキュリティソフトやファイアウォールが `python.org`（約 12 MB）への通信を止めていないか確認し、`Install.cmd` を再実行してください。SHA-256 検証に失敗したファイルは実行されません。
- **特定の行やプロローグ動画だけ片方の言語しか出ない：** ゲーム原版データの欠落仕様によるものです（プロローグ動画に繁体字字幕がない等。下記「対象範囲」参照）。
- **解決しない場合：** [SUPPORT.md](https://github.com/snowyukitty/psycho-sleuth-subtitles/blob/main/SUPPORT.md) または [GitHub Issues](https://github.com/snowyukitty/psycho-sleuth-subtitles/issues) をご確認ください。

## 対象範囲・プレビュー版の制限

- シナリオの会話、選択肢、動画字幕（22本の `.srt` セット）が対象です。メニュー、キャラクター名、手がかり UI はゲーム側で選んだ言語のまま維持されます。
- 通常は上下二段表示ですが、表示密度の高い一部の枠では元のクリック感を保つため、同じ上下順で同一行に併記します。原文が完全一致する場合は1回だけ表示します。
- 原版のプロローグ動画には繁体字字幕がありません。繁体字を含む組み合わせでは、もう一方の選択言語だけを表示します（簡体字を選んだ場合は簡体字を表示）。動画字幕の表示タイミング差により一時的に片側のみ表示される区間があります。選んだ2言語が揃わない会話行は元のまま残るため、ゲーム側の現在の設定言語で表示されます（空欄の場合もあります）。
- 繁体字と簡体字には、ゲームに収録された**それぞれの独立翻訳**を使用します（自動変換は行いません）。
- 対応する未改変ファイル、または本ツールで適用された状態のみ受け付けます。12通りの隔離データ検証（ボイス・制御データの保持を含む）は合格していますが、長文・選択肢・英語/簡体字ゲーム内 UI フォント設定・動画字幕の実際のゲーム画面上での目視検証は未完了のため、上記の推奨設定（繁体字中国語または日本語 UI）をご利用ください。
