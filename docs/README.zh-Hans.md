# 异病侦探 Psycho-Sleuth 双字幕 — 使用说明

[English](README.en.md) · [日本語](README.ja.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md)

这是非官方的 **Windows x64 预览版**，使用游戏本机已有的翻译组合双字幕。不新增配音，不需要 API key，不上传游戏文本，也不包含游戏素材或完整剧本。

## 安装

1. 从 [Release 页面](https://github.com/snowyukitty/psycho-sleuth-subtitles/releases/tag/v0.2.0-preview.1)下载 **Psycho-Sleuth-Subtitles-0.2.0-preview.1-Minimal.zip**。
2. 将整个 ZIP 解压到可写入的文件夹。保留 `_tool` 文件夹，与启动文件放在一起。
3. 关闭游戏，暂停 Steam 更新，双击 **Install.cmd**。
4. 工具通常会自动找到 Steam 游戏；如果要求输入路径，粘贴游戏文件夹路径即可。游戏文件夹必须可写入。
5. 先选**上方字幕**，再选**下方字幕**。两个画面的编号相同；下方菜单会排除已选的语言。

| 编号 | 语言 |
| --- | --- |
| 1 | English — 英文 |
| 2 | 日本語 — 日文 |
| 3 | 繁體中文 — 繁体中文 |
| 4 | 简体中文 |

任选两种不同语言，共 **6 种配对、12 种上下排列**，包含繁中／简中。例如 **1 → 4** 是英文在上、简中在下；**4 → 1** 则相反。选好下方语言后立即开始安装。第一个画面可按 **R** 还原、**0** 退出；第二个画面按 **0** 返回。注意：新版编号4是简体中文，还原请用 R 或 Restore.cmd。

6. 游戏内的文本语言请选择 **繁体中文或日文**。对译齐全的对话在两种设置下都会显示本工具选定的字幕组合；例外请见下方“范围与预览限制”。

首次运行需要联网，会下载约 **12 MB** 的官方 Python 运行环境，并在执行前核对 SHA-256。不需要自行安装 Python，也不会改动系统的 Python。下载的运行环境会保留在 `_tool` 内，供下次使用。

## 切换与还原

关闭游戏后，再次运行 Install.cmd 即可切换组合。双击 **Restore.cmd** 可以精确还原原版文件。备份位于 `Psycho Sleuth_Data/.psycho-sleuth-subtitles/original`，还原完成前请保留。如果安装中断，请重新运行 Install 或 Restore，恢复完成前不要启动游戏。

**从 0.1.0-preview.1 升级：** 将新版 ZIP 解压到另一个文件夹，运行新版 Install.cmd。工具确认旧版安装状态后，会沿用已验证的原版备份，不需要手动还原。请保留游戏内的 `.psycho-sleuth-subtitles` 文件夹。如果 Steam 或其他工具改过文件，仍须通过兼容性检查。

Steam 更新游戏后，**请勿用旧备份覆盖新文件**。工具会拒绝未知版本和其他模组。如果恢复被拒绝，请先完成 Steam 的 **“验证游戏文件的完整性”**，再将 `.psycho-sleuth-subtitles` 文件夹移到游戏之外保留，等待支持新版本的工具。

## 范围与预览限制

- 支持剧情对话、剧情选项、过场字幕；菜单、名称、线索界面保持游戏选定的语言。
- 多数字幕上下排列；少数密集短句按选定顺序使用同行对照，保留原有点击节奏。原文完全相同时只显示一次。
- 原版序章动画缺少繁体中文字幕；含繁中的配对在该处只显示另一种选定语言，选简中就显示简中。原始字幕时间不同的区间，也可能短暂只显示一种语言。所选两种译文不齐全的对话行保持原样；如果游玩时遇到这些行，会按游戏当前的文本语言显示（也可能为空白），不会显示选定的双字幕。
- 繁体与简体中文分别使用游戏原有的**独立译文**，不通过自动繁简转换。
- 接受已支持且未经修改的原版文件，或可识别的本工具安装状态。12 种排列已通过隔离数据测试；长句、选项、字体及过场字幕的实际游戏画面验收仍未完成。英文及简中游戏界面设置的字体显示尚未验收，请先使用上述建议的游戏文本设置。
